## Fixed

- **"Installed" now means the game is actually there.** The console was listing a title as
  installed whenever its artwork folder existed — which is left behind by a failed install and
  survives a database reset. Pressing Install on something the console did not have could answer
  "Done" and then show it as installed, with nothing downloaded. Both consoles now require the
  title's own data on disk. On a real console this removed **29 titles** that were never installed.
- **An install no longer reports "Done" before it has happened.** It says it has been queued, and
  the install queue reports how it ends.
- **The app's own tile shows the version that is running.** It was reading a number recorded when
  the build was made, so a console running 3.87.0 said 3.86.0 and was offered an update it already
  had.
- **A second PC can take updates.** A companion without the files refused every update it offered;
  it now downloads them.
- **The companion no longer gets stuck on an old console address.** If a console moves and also
  changes its identity, the app finds it again instead of asking a dead address for ever — which
  had been making every PS4 tile look unreachable.
- **A console with no PC no longer claims everything is up to date** when it could not check at all.
  It checks this project's releases on its own and tells you when a newer version exists.
