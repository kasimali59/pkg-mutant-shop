## Fixed

- **An app you deleted no longer shows as installed.** The panel asked the console once, when you
  opened it, and then kept answering from that first reply for as long as you were looking — so
  anything you removed from the console stayed on screen as **Installed**. It also counted titles a
  console merely lists but has not installed, which is what a deleted app looks like for a while.
- **Updating this app actually sticks.** On a PC that did not already hold our PS4 payload, taking
  the update reported success and changed nothing, so the same update came back on the next
  refresh, for ever.
- **Sending our own payload to a console works again.** The app skipped the transfer when the file
  was already the same size, and our builds are the same size from one release to the next — so
  the console kept running the previous one.
- **The version shown for this app is the one you have.** On a PC without the file, the panel
  reported the version recorded when the app was built rather than the one it carries.
- **"Not installed" is no longer printed when the app cannot tell.** The tab you are on and the
  console being described can differ; that case now says so instead of guessing, and a press on it
  asks before installing over the top.
- **The Updates list re-checks instead of assuming.** Taking an update cleared the badge on trust,
  and the list was frozen once filled — an update taken on another PC or phone kept its row.

## New

- **The app restarts itself after updating itself.** It replaces its own Windows app, starts the
  new build and closes the old one. Nothing to close and reopen by hand. Set
  `updates.auto_restart` to `false` in `config.json` to be told instead.
