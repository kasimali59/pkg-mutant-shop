## Fixed

- **The PS5 app works again after a system update.** If you update your console, the build has to be
  made with a toolchain that knows that firmware — otherwise the app cannot start at all: Payload
  Manager reports success, and nothing happens. No message, no process, nothing in any log. This
  build is made against a toolchain that knows firmware **13.60**.

## New

- **The console reports its firmware.** It now appears in the console's own health, and the app
  remembers it — so when it changes you are told, with a note that the app may need a newer build.
  That one line is the difference between knowing in a second and guessing for an hour.

## For anyone building this themselves

`bash ps5-app/update-sdk-wsl.sh --check` says which firmwares your toolchain knows and what is
available upstream. Without `--check` it updates it and keeps the old one. The setup script only
ever fetched the toolchain **once**, so it quietly stayed on whatever was current the day the
machine was set up.
