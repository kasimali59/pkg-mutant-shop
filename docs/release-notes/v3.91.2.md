## Fixed

- **Update all finishes before the app restarts.** The restart used to happen the moment this app's
  own row succeeded, which cut the rest of the list off mid-download. It now waits until you have
  stopped taking updates.
- **Nothing is left beside the app.** A self-update could leave the previous build, and sometimes a
  half-finished download, sitting next to the app — tens of megabytes of nothing. Both are cleared
  on the next start, and it keeps trying for a minute if Windows is still holding one.
