## Fixed

- **The PS4 could stop accepting installs.** Every time the payload loaded it installed its own
  home-screen icon, and the engine then reported itself busy from that point on — so later installs
  were refused on a console that was free. It now reports what is actually running.
- **Asking what an install would do no longer performs one.**

## Checked on hardware

- Every bundled payload on both consoles starts from the console itself, with no PC on the network.
- Every homebrew's install was exercised on the console it belongs to. RetroArch is correctly
  refused — it is an app folder, not a package, so it goes on a drive the console mounts.
- **FPKGi is refused by both consoles.** The package is intact and the install lane is free; the
  consoles simply decline it. That is theirs to decide — the app now reports it as an error instead
  of claiming it worked.
