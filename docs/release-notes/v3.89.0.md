## Fixed

- **Homebrews install again — all of them, on both consoles.** The app was serving each one under
  its path inside your folder, and a console's installer cannot fetch a URL containing a space or
  a bracket. One space in a folder name was the whole difference: FPKGi, PS4-Xplorer and the PS5
  Internet Browser all failed for it, while Itemzflow worked because its folder happened to have
  none. They are now served under a clean address.
- **The PS5 could send a truncated reply** to the panel once its answer grew past a fixed size.
- **A mounted app shows as installed.** A folder app has no package on disk, so it was listed as
  not installed while sitting on the home screen.

## New

- **Folder apps install.** An app folder like RetroArch is sent to the drive ShadowMountPlus
  watches and mounts itself from there — the same route the app already uses for a game stored
  unpacked. PS5 only; a PS4 is told why instead of being sent a folder it cannot mount.
