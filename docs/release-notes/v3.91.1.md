## Fixed

- **Updating both tiles at once no longer reports an error.** This app appears once per console, so
  taking both — or pressing **Update all** — asked it to replace itself twice. The first went
  through and the second said *"Could not set the running app aside"*, on a PC that had in fact
  updated perfectly. It replaces itself once per release now.
